# Study Organizer

Projeto desenvolvido para a disciplina de Bootcamp II.

A ideia da aplicação é ajudar estudantes a organizarem suas tarefas de estudo de forma simples, utilizando o terminal.

---

## Público-alvo

Estudantes que têm dificuldade em manter uma rotina de estudos organizada.

---

## Funcionalidades

- Adicionar tarefas
- Listar tarefas
- Remover tarefas

---

## Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/GuiBFN/study-organizer.git
cd study-organizer
```
2. Instalar as dependências
```bash
pip install -r requirements.txt
```
3. Executar o programa
```bash
python -m src.main
```
